# FUTURE_UIUX_TASK01

Restaurant Menu App - UI/UX Design Task
📌 Project Overview
This project focuses on designing a seamless, intuitive, and visually appetizing digital menu for a modern dining experience. The goal was to bridge the gap between physical menus and a fluid mobile ordering process.

Role: UI/UX Design Intern

Tool Used: Figma 

Duration: 2 Days

🔍 The Problem
Traditional paper menus are often difficult to update and lack high-quality visuals. For a mobile app, the challenge is to present a large number of food items without overwhelming the user, while making the checkout process as fast as possible.

🎨 Design Process
1. Wireframing (Low-Fidelity)
I focused on a bottom-navigation structure to ensure easy thumb reach. Key screens mapped out included:

Home (Featured/Trending items)

Category Listing (Chaats,Rice&Biryani,Deserts,Beverages)

Product Detail Page (Customizations/Add-ons)

Cart & Checkout(Payment and Billing)

2. Visual Identity
Typography: ( Inter for readebility and Inter medium for the headings )
Color Palette: ( #000000,#FFFFFF,#FF6619,#E9E9E9 ).

Iconography: Minimalist line icons to keep the UI clean.
